About Elara

Elara AI & OS is a software project developed and maintained by Sparsh Saxena.


The project explores the combination of artificial intelligence, voice interaction, computer vision, automation, graphical interfaces, maps, skills, plugins, and modular software components.

Features

Elara brings multiple AI and desktop capabilities together in one modular Python-based project.

AI Assistant

AI-powered question answering, conversations, and assistant functionality.

Voice Interaction

Voice interaction and speech-related capabilities.

Computer Vision

Image understanding, screen analysis, and computer vision features.

OCR

Optical character recognition and visual information processing.

Automation

Commands, automation systems, skills, and modular workflows.

Desktop GUI

Graphical desktop components designed for interacting with Elara.

Maps & Location

Maps and location-related software components.

Modular Architecture

A modular project structure containing different AI and software components.

Experimental Development

Gesture-Controlled Floating Desktop Interface

Elara also includes an experimental camera-based interaction system developed and tested privately by the developer.

  • Camera-based interaction
  • Hand gesture interaction
  • Floating desktop interface elements
  • Gesture-controlled movement
  • Gesture-controlled resizing
  • Repositioning floating elements
  • Touch-free desktop interaction

Status: Experimental / Private Development
